生产环境变量（IDEA 分号分隔）

ctrl_server：
CTRL_SERVER_BIND_HOST=127.0.0.1;CTRL_SERVER_PORT=9002;CTRL_SERVER_TLS_PORT=9443;CTRL_SERVER_TLS_CERT=D:\Code\Rust\my\real_time_ctrl\target\prod\certs\server.crt;CTRL_SERVER_TLS_KEY=D:\Code\Rust\my\real_time_ctrl\target\prod\certs\server.key;CTRL_SERVER_AUTH_SECRET=<从部署秘密存储注入的至少32字符随机值>;RUST_BACKTRACE=1

real_ctrl / real_ctrl_invoker_http_service：
REAL_CTRL_SERVER_HOST=127.0.0.1;REAL_CTRL_SERVER_PORT=9002;REAL_CTRL_TLS_PORT=9443;REAL_CTRL_TLS_SERVER_NAME=real-ctrl-server;REAL_CTRL_TLS_CA_CERT=D:\Code\Rust\my\real_time_ctrl\target\prod\certs\server.crt;REAL_CTRL_TLS_SERVER_SPKI_SHA256=<服务端叶子证书SPKI-SHA256十六进制>;REAL_CTRL_AUTH_SECRET=<与服务端一致的部署秘密>;REAL_CTRL_API_TOKEN=<至少32字符的独立随机API令牌>;RUST_BACKTRACE=1

说明：
- ctrl_kik 不配置环境变量，继续使用编译期 HOST()/PORT()/LOCK_FILE_PATH()。
- 控制面认证秘密不再写入 common/config.json 或二进制；生产应由 Windows 服务配置、CI/CD secret 或等价秘密存储注入，且不能与 HTTP token 复用。
- 明文控制兼容需服务端和客户端分别显式设置 CTRL_SERVER_ALLOW_PLAIN_CTRL=1 / REAL_CTRL_ALLOW_PLAIN=1；生产禁止设置。
- Exec 默认经过三层关闭：real_ctrl API、ctrl_server 策略和 ctrl_kik 构建。确需启用时分别配置 REAL_CTRL_API_ALLOW_EXEC=1、CTRL_SERVER_ALLOW_EXEC=1，并用 --features dangerous-exec 构建 ctrl_kik。
- 以上证书是本仓库内生成的 127.0.0.1 本机部署证书；如果替换生产证书，必须同步替换 REAL_CTRL_TLS_CA_CERT 和 REAL_CTRL_TLS_SERVER_SPKI_SHA256。
- real_ctrl HTTP 默认读取 config/app.toml，本项目当前默认绑定 127.0.0.1:9000。
