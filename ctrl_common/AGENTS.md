# ctrl_common 维护规则

## 职责边界

`ctrl_common` 承载控制侧业务帧、命令响应和服务端返回结构。它依赖 `common` 的底层协议能力，但不应直接处理 TLS、管道或 HTTP。

## 协议约束

- `Frame::from_buf` 和响应解析必须对空帧、短帧、未知类型安全返回 `None`。
- 业务帧新增类型时，需要明确它属于控制通道还是数据通道。
- 大块数据只允许出现在明确的数据帧中，不能塞进普通响应字符串。

## 测试要求

- 新增或修改帧类型后，补 round-trip 与畸形输入测试。
- 修改本 crate 后运行 `cargo test -p ctrl_common`。
